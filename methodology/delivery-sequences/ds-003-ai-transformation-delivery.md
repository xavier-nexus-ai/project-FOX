# Delivery Sequence 3: AI System Build (90-Day Transformation)

**Name:** AI System Build Delivery Sequence
**Applies to:** AI Orchestration engagements — clients building a custom AI framework from their IP (consultancies, agencies, educators, SaaS companies, professional services firms)
**Purpose:** Map the 90-day delivery sequence for an AI System Build, from pre-engagement handover through to first production deployment.

## Phase 1: Pre-Engagement (Week 0)

### Sales Handover

When a deal closes, the following transfers from sales to delivery:
- Client name, company, industry, business model
- Primary offer and pricing
- Revenue and team size (if shared)
- What the client said they want from the engagement (in their own words)
- Source materials (websites, courses, SOPs, documents)
- Communication preferences and timezone

### Client Prerequisites

- Access to existing IP materials (courses, frameworks, SOPs, templates)
- A dedicated project folder
- Claude Code installed and valid API key
- 4-6 hours per week blocked for 12 weeks
- A single point of contact (not a committee)

### Kick-Off Meeting (60 minutes)

1. Introductions and expectations alignment (10 min)
2. Walk through 90-day roadmap (15 min)
3. Explain client's role and time commitment (10 min)
4. Discovery interview — capture business context (20 min)
5. Next steps and first session booking (5 min)

### Initialization

After kick-off, the Initialization Agent runs to create the COS and personalised CLAUDE.md.

## Phase 2: Immersion (Weeks 1-4)

**Purpose:** Get the client AI-literate, set up the environment, and give them a tangible quick win.

### 2.1 AI Literacy Education (Weeks 1-2)

Conversational education adapted to the client's current AI knowledge level. Six core topics woven into natural conversation:

1. What agents are
2. What skills are
3. What the COS is
4. How multi-chat workflows work
5. AI possibilities for their industry
6. Claude Code as a platform

**Deliverables:**
- AI Possibilities Map
- AI Literacy Assessment

### 2.2 Industry AI Analysis (Weeks 2-3)

Live research into the client's industry covering: industry AI landscape, competitor AI usage, opportunity gaps, risk and threat assessment, 12-month trend forecast.

**Deliverable:** Industry AI Report (1,500-3,000 words)

### 2.3 Stack Configuration (Weeks 3-4)

1. Audit existing tools and environment
2. Configure only needed MCP servers
3. Teach through 4 practical exercises
4. Validate systematically

**Deliverable:** Stack Validation Report

### 2.4 Quick Win Build (Week 4)

Hands-on session where the client builds something tangible using AI tools (Lovable, Cursor, or similar). Delivery lead working alongside the client. Purpose: build confidence before the deep extraction work begins.

### Immersion Exit Gate

- [ ] AI literacy confirmed
- [ ] AI Possibilities Map completed
- [ ] Industry AI Report completed
- [ ] Stack configured and validated
- [ ] Client can independently operate an agent
- [ ] Quick win build completed

## Phase 3: Mapping (Weeks 5-8)

**Purpose:** Extract everything the client knows, then structure it into a system design.

**Non-negotiable dependency chain:**
```
IP Extraction (Weeks 5-6)
    v
Methodology Architecture (Weeks 6-7)
    v
Diagnostics Design (Week 7)   ---   Constraint Mapping (Weeks 7-8)
                                           v
                                    Leverage Planning (Weeks 7-8)
```

### 3.1 Business Workflow Mapping

Map the complete business from end to end. Three-level workflow map covering every core product/service from initial enquiry through fulfilment.

### 3.2 IP Extraction (Weeks 5-6) — The Most Important Work

Multiple deep-dive interview sessions to extract five categories of IP:

| Category | Minimum Required |
|----------|------------------|
| Frameworks | 2+ |
| SOPs | 3+ |
| Judgement Calls | 5+ |
| Vocabulary | — |
| Delivery Sequences | — |

**The DEPTH model for extraction:**
- **D**ocument first — read everything before asking
- **E**licit through scenarios — never "what is your process?", always "imagine a client comes to you with..."
- **P**robe the gaps — when expert jumps from step 2 to step 4, find what happened at step 3
- **T**est understanding — reflect back, let expert correct and refine
- **H**unt the tacit — push past "I just know" to find the actual signals

**Client time commitment peaks here:** 4-6 hours across Weeks 5-6.

### 3.3 Methodology Architecture (Weeks 6-7)

Structure extracted IP into a named, phased methodology:
1. Survey raw IP
2. Identify transformation arc
3. Propose 3-7 phase structure
4. Name the methodology collaboratively (3-5 options, client picks)

### 3.4 Diagnostics Design (Week 7)

Four types of diagnostic instruments:
1. Intake Assessment (10-20 questions, 3-5 result profiles)
2. Scoring Rubrics (3-5 maturity levels per dimension)
3. Phase Progress Diagnostics (checkpoints at phase boundaries)
4. Triage Tools (if applicable)

### 3.5 Constraint Mapping (Weeks 7-8)

Every process classified into one of four categories:
- **Fully Automated** — AI end-to-end
- **AI-Assisted** — AI does it, human reviews
- **AI-Augmented** — Human leads, AI supports
- **Human Only** — No AI involvement

### 3.6 Leverage Planning (Weeks 7-8)

Five elements designed: pricing model, offer packaging, delivery model redesign, scaling strategy, financial projections.

### Mapping Exit Gates

- [ ] Business workflows mapped end-to-end
- [ ] IP Vault populated: 2+ frameworks, 3+ SOPs, 5+ judgement calls
- [ ] Methodology named and structured
- [ ] Diagnostics designed
- [ ] Constraint map created
- [ ] Leverage plan completed
- [ ] Scaling roadmap delivered

## Phase 4: Transformation (Weeks 9-12)

**Purpose:** Convert Mapping outputs into a working, deployable AI framework.

### 4.1 Framework Construction (Weeks 9-11)

Build all 10 deliverables in prescribed order:

| Order | Component | Builder Skill |
|-------|-----------|---------------|
| 1 | COS Schema | cos-design-expert |
| 2 | Framework Architecture | framework-pattern-expert |
| 3 | Agents | agent-design-expert |
| 4 | Skills | skill-design-expert |
| 5 | Methodology Wiring | methodology-structuring |
| 6 | Diagnostics | diagnostic-builder |
| 7 | Playbooks | playbook-builder |
| 8 | Gates | blocking-gate-designer |
| 9 | Deploy Script | deploy-script-builder |
| 10 | CLAUDE.md | claude-md-builder |

Plus: workflows, tasks, checklists, README.

**The separation principle:** The framework being built is entirely separate from the builder framework being used to build it.

### 4.2 QA Validation (Weeks 11-12)

Independent quality assurance across 10 categories with binary pass/fail:
1. Structural | 2. Frontmatter | 3. Agent | 4. Skill | 5. COS Schema
6. Workflow | 7. IP Fidelity | 8. Deploy Script | 9. CLAUDE.md | 10. Cross-Reference

### 4.3 Deployment (Week 12)

- Framework deployed via deploy script
- Client training on all framework operations
- First real customer deployment with delivery lead supporting

### Transformation Exit Gates

- [ ] All 10 components built
- [ ] QA validation passed
- [ ] Deploy script tested
- [ ] Client trained
- [ ] First customer deployment successful

---

## The 10 Deliverables

1. Named Methodology — branded, phased transformation
2. Diagnostic Instruments — assessment tools
3. Playbooks — operational guides per phase
4. Templates — document templates
5. AI Agents — specialist personas with client IP
6. Skills — modular expertise modules
7. Workflows — phase execution sequences
8. Tasks — discrete work units
9. Client Operating System (COS) — state file
10. Deploy Script + Scaling Roadmap — one-command deployment + commercial plan

**Total client commitment:** ~40-50 hours across 12 weeks.

---

## Common Failure Modes

| Failure | Cause | Prevention |
|---------|-------|-----------|
| Shallow IP extraction | Not enough sessions, surface-level questions | Budget 3-5 sessions minimum, use DEPTH model |
| Generic framework | IP not baked into agents/skills | QA checks IP fidelity, flag generic output |
| Methodology naming stalls | Client can't decide | Present 3-5 options with rationale, set decision deadline |
| Scope creep in Mapping | Client keeps adding "one more framework" | Gate minimums exist for a reason — stay disciplined |
| Week 12 crunch | Earlier phases ran over time | Gates prevent this — flag early if Immersion runs long |
